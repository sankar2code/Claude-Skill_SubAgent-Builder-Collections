# 02 · Needs Map

**Stage:** Diagnose · **Updates:** `needs`

## Purpose

Turn evidence into customer needs written as outcomes, with importance, and where possible satisfaction, so unmet needs stand out.

## Inputs

- Evidence (E#)
- Segments

## Steps

1. Write each need as a customer outcome: "minimize time to…", "reduce the chance of…". No product or feature words.
2. Link each need to the evidence that supports it.
3. Set importance 1–10 from evidence (survey data first). If judged, label `[HYPOTHESIS]` and say whose judgment.
4. Add satisfaction where known. Unmet = important and poorly satisfied.
5. Note which segment each need belongs to; the same need can differ by segment.
6. Mark the top 3–5 needs. Name any need you are deliberately not addressing.

## Check before moving on

- [ ] Needs are outcomes, not features.
- [ ] Each need cites evidence.
- [ ] Importance source stated.
- [ ] `python scripts/canvas_check.py canvas-output/canvas.json` has no errors

## Common mistake

- Writing solutions as needs ("needs a dashboard").
