# 04 · Strategic Choices

**Stage:** Analyze · **Updates:** `choices`

## Purpose

Make the trade-offs explicit: what the team will do, and what it will deliberately not do, and why.

## Inputs

- Opportunities
- Constraints
- Strategy Sprint decision if available

## Steps

1. For each major direction, write a pair: "We will…" / "We won't…", plus the rationale tied to evidence or constraints.
2. Test each "won't": would a reasonable competitor choose it? If nobody would, it is not a real trade-off.
3. Cover the main trade-off types: segment focus, build vs partner, speed vs depth, automation vs control, price vs reach.
4. Note what would make the team revisit each choice.

## Check before moving on

- [ ] Every "will" has a real "won't".
- [ ] Rationale cites evidence or a constraint.
- [ ] `python scripts/canvas_check.py canvas-output/canvas.json` has no errors

## Common mistake

- Slogans ("we will delight customers") that exclude nothing.
